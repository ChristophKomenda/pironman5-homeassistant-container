# Accessibility

We aim to make the Pironman 5 Home Assistant integration usable with Home Assistant's built-in accessibility features.

## Supported environments

The integration exposes native Home Assistant entities rather than a separate custom dashboard. Accessibility of controls depends on the installed Home Assistant frontend, assistive technology, and device.

## Known limitations

- Some Pironman features depend on hardware and upstream API capabilities.
- This project has not completed a formal accessibility audit.
- Custom dashboards created by users are outside this project's scope.

## Reporting barriers

Please open an issue describing the affected Home Assistant version, assistive technology, steps to reproduce, expected behavior, and screenshots if useful. Avoid sharing private data.

Accessibility improvements and testing contributions are welcome.
