# v1.4.0 — Extended Hardware Diagnostics & Pro Max Readiness

Development patch; requires tests before release.

- Read-only network IP diagnostic sensors via optional GET /api/v1.0/get-ips,
  polled no more than once per minute. MAC addresses are not exposed.
- Diagnostic export allowlists model, vendor version, peripheral names,
  interface names, disk device names and update status (not host, IP, MAC or logs).
- Model sensor additionally reports vendor software version and capabilities.
- Read-only RGB LED count from get-config when present.
- `supports_explicit` checks positively confirmed device capabilities. Existing
  `supports` behavior remains compatible with older Pironman firmware.

No additional services, containers or dependencies. The Pro Max still needs
physical testing; touchscreen, camera, speaker, IR and button events do not
have verified REST endpoints. Fan controls must not be inferred from model
names. RGB LED count remains read-only until safe per-device limits are known.

Run `python -m pytest -q`, HACS validation and hassfest; then test on
maintainer hardware before merging or releasing.
